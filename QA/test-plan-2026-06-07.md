### TEST-CAT1-001: Posicionamiento sub-pixel (0.1px)
**Categoría:** CAT 1 — Precisión de Diseño
**Prioridad:** P0
**Pasos:**
1. Abrir editor en https://bejewelled-llama-a6719d.netlify.app
2. Crear un rectángulo en el canvas
3. En PropertiesPanel, en "Position & Size", ingresar X=100.5 y Y=200.3
4. Verificar que los valores se mantienen (no se redondean)
5. Exportar el canvas como JSON
6. Buscar el objeto en el JSON — verificar left=100.5, top=200.3
7. Reimportar el JSON — verificar que el objeto conserva las posiciones exactas

**Resultado esperado:** Posiciones sub-pixel (0.1px) se mantienen exactas en todo el ciclo create → edit → export → reimport
**Resultado real:** [a llenar]
**Archivos afectados:** `src/components/PropertiesPanel.tsx`, `src/hooks/useCanvas.ts`
**Funciones afectadas:** `em()` (redondea con `Math.round()`), `commit()`, `canvasToJSON()`
**Severidad:** Mayor — `em()` usa `Math.round()` que elimina precisión decimal
