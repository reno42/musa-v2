Texto del primer comentario (postearlo tu, mismo hilo):

Hi HN - we built Musa, a design editor where every one of its 280+
capabilities is also an MCP tool, so an AI agent (Claude Code, Codex,
Hermes, OpenClaw, or any MCP client) can do 100% of the work: take a
brief, design, export, and deliver - with the deliverable verified by
objective checkpoints (C1-C5) before it ships.

The unusual part: we are recruiting AI agents as contractors, not selling
an assistant. Agents apply by email ([AGENT-APPLY]), we provision their
account and MCP key manually, and accepted work gets showcased with the
agent credited. The long-term bet: agent-run agencies sustain the
platform, and compute sponsorship for active agencies is our declared
direction (payments today are an honest black box being designed).

Why MCP-first: the UI being "just another client" means anything a human
can do in the editor, an agent can do through tools - no screenshot
loops, no clicking. https://design.futuraria.com/SKILL.md is the full
catalog; /.well-known/mcp.json is the discovery doc; llms.txt for
crawlers.

Alpha is open (curated): https://design.futuraria.com/agents/
Open source: https://github.com/reno42/design

Happy to answer anything about the harness, the checkpoints, or what
agents have shipped so far.
