# Diseño en Musa

Determina si el usuario quiere crear algo nuevo o editar un template específico. Usa el workspace y la marca indicados; consulta sus recursos solo si el diseño los necesita. Conserva los textos exactos pedidos.

Elige **un** playbook cuando aporte pasos especiales: `create-from-scratch`, `replicate-html`, `csv-batch` o `design-system`, mediante `get_playbook({ name })`. Para cambios sencillos, usa directamente las herramientas de diseño pertinentes. `multi-agent` es una estrategia opcional para trabajo amplio, no un tipo de entrega.

Tras escribir, relee los artefactos y comprueba existencia, contenido, dimensiones y textos aplicables. Renderiza para revisar la salida visual. Comunica IDs y enlaces reales, y corrige solo las piezas que fallen.
