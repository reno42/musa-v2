# Configuración en Musa

Identifica el tipo de configuración y sus campos requeridos. Valida una credencial con una llamada real cuando el ajuste usa credenciales; no exijas esa prueba para un cronjob u otro ajuste que no las tenga. Guarda mediante la herramienta específica, relee el estado activo y comunica qué quedó configurado. Nunca copies secretos a respuestas, bitácoras o instrucciones de otro agente.

## Ejemplos

- "Conecta mi clave de Gemini para que la uses en los flujos"
- "Crea una clave MCP para mi nuevo agente con rol editor"
- "Configura un webhook saliente para avisar a mi N8N cuando se publique una pieza"
